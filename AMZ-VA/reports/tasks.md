# AMZ-VA Tasks & Follow-Ups

This is the owner's persistent memory across separate Claude Code sessions.
Nothing in this file is invented — an item is only added when the owner
actually raises it, or when something from a real analysis genuinely needs
follow-up.

## How to use this file

- Read this file at the start of a session, especially before answering
  anything like "what should I work on today."
- When the owner mentions something to follow up on, a product to
  re-check, or a task to remember — add it here before the session ends.
- Mark items done (`- [x]`) rather than deleting them, so there's a simple
  history of what's been handled.
- Keep entries short (a line or two). A full deal writeup belongs in
  `AMZ-VA/deals/analyzed/`; a full report belongs in `AMZ-VA/reports/`.
- Never add a task, deadline, or business fact that wasn't actually stated
  — if unsure whether something belongs here, ask instead of guessing.
