# Deal Tracker

A running, one-line-per-deal summary of everything analyzed in
`AMZ-VA/deals/analyzed/`. This file is the at-a-glance index — the full
PRODUCT/COST/AMAZON/PROFITABILITY/DEMAND/RISK/FINAL ANALYSIS writeup for
each deal lives in its own file there.

## How to maintain this file

- Add one row whenever a deal analysis is saved to `AMZ-VA/deals/analyzed/`
  — don't recreate this whole file, just append.
- Only add a row for a deal that was actually analyzed — never a
  placeholder or hypothetical/test deal (those stay in chat, not here).
- Link the "Analysis" column to the actual file in `deals/analyzed/`.
- Keep rows short — the full detail belongs in the linked file, not here.
